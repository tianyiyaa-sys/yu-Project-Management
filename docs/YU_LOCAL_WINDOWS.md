# 雨诺项目经营工作台｜Windows 本地测试

面向产品验收，不要求使用者理解开发环境。

## 日常使用

- 双击 `启动雨诺项目工作台.bat`：启动并打开浏览器
- 双击 `停止雨诺项目工作台.bat`：停止本地服务
- 双击 `更新到最新版.bat`：拉取 `yu-pmo-v1` 最新代码、重新构建并打开

访问地址：

http://localhost:3000

## 第一次启动

第一次会从源码构建 WeKan，并下载数据库相关镜像/组件，因此明显比后续启动慢。

Docker Desktop 必须处于运行状态。

## 数据

本地数据保存在 Docker volume 中。普通停止或重新构建不会清空项目数据。

## 数据源边界

- WeKan：项目执行、任务、看板
- RBC：合同、回款、工时（后续通过接口接入）
- 雨诺 PMO：阶段、风险、经营视图
- 小雨 AI：诊断、预警、报告

不要在仓库中写入 RBC 密钥、客户密码或生产 Token。
